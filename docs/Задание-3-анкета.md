# Задание 3. Работа с текстовыми файлами в Flutter

Выполнено в существующем проекте CodeBug по заданию `З3_Flutter (1).pdf`.

## Как открыть

На экране входа нажми **«Анкета без входа»**. Сервер и аккаунт для работы анкеты не нужны. Внутри аккаунта открой **Профиль → Анкета · сохранить в файл**: имя и email подставятся из профиля.

1. Заполни имя, возраст, email и телефон.
2. Пока хотя бы одно поле некорректно, **«Сохранить данные»** недоступна.
3. Нажми кнопку. Во время записи поля и кнопки заблокированы от повторного нажатия.
4. На Mac/Android/iOS приложение дописывает запись в `anketa.txt` в каталоге документов приложения. После успешной записи оно показывает сообщение и полный путь. На Mac этот путь можно скопировать и открыть в Finder через «Переход → Переход к папке» (перейти в папку, содержащую файл).
5. **«Очистить форму»** очищает все четыре поля, включая предварительно подставленные имя и email. Уже сохранённый файл остаётся на устройстве.

В браузере Dart не имеет прямого доступа к произвольной папке устройства. Поэтому web-версия создаёт UTF-8 файл `anketa.txt` и передаёт его браузеру для скачивания. Папку выбирает браузер/пользователь. Каждый файл содержит одну анкету. Браузер может добавить номер к имени повторно скачанного файла. Сообщение в web-версии подтверждает передачу файла браузеру, а не утверждает, что пользователь завершил скачивание.

## Правила проверки

- Имя: обязательное, до 80 символов, без переводов строк и управляющих символов.
- Возраст: целое число от 1 до 120.
- Email: обязательный, формат `имя@домен.зона`, без пробелов внутри, до 254 символов.
- Телефон: 10–15 цифр. Допустим `+` в начале, пробелы, скобки и дефисы. При сохранении пробелы, скобки и дефисы удаляются.
- Пробелы по краям значений удаляются. Переводы строк запрещены, чтобы введённое значение не меняло структуру файла.

## Формат anketa.txt

```text
Имя: Иван Иванов
Возраст: 25
Email: ivan@mail.com
Телефон: +77001234567
---
```

Кодировка UTF-8 сохраняет кириллицу. На нативных платформах `FileMode.append` добавляет новые анкеты в конец файла, разделитель `---` отделяет записи. Данные анкеты не отправляются в API и не сохраняются в серверную SQLite.

## Ответы на контрольные вопросы

**1. Какие пакеты используются во Flutter для работы с текстовыми файлами?**

На мобильных устройствах и компьютерах используются библиотека Dart `dart:io` (класс `File`) и пакет `path_provider` для получения доступной папки. `dart:convert` задаёт UTF-8. В web-версии этого проекта используется `package:web`: Blob и ссылка скачивания. `shared_preferences` подходит для небольших настроек, но не заменяет запись обычного текстового файла.

**2. Как обеспечить валидацию данных в текстовых полях формы?**

Разместить `TextFormField` внутри `Form`, задать каждому полю `validator`. Валидатор возвращает `null` для правильного значения и текст ошибки для неправильного. `FormState.validate()` повторно проверяет форму перед записью. Изменения контроллеров обновляют доступность кнопки: `onPressed: valid && !saving ? save : null`.

**3. Как реализовать запись данных в локальное хранилище устройства?**

Получить папку через `getApplicationDocumentsDirectory()`, сформировать путь к `anketa.txt`, создать `File` и дождаться завершения `writeAsString(text, mode: FileMode.append, encoding: utf8, flush: true)`. Сообщение об успехе показывается только после завершения операции. Исключения обрабатываются через `try/catch`, введённые данные при ошибке сохраняются в форме для повтора.

**4. Что происходит, если попытаться записать данные в файл, не указав путь для сохранения?**

Конструктор `File` требует строку пути. `File('anketa.txt')` задаёт относительный путь: файл создаётся относительно текущего рабочего каталога процесса, а не автоматически в документах приложения. Рабочий каталог может быть недоступен для записи, тогда возникнет `FileSystemException`. Пустой путь также не задаёт корректное имя файла. Поэтому приложение получает доступную папку явно через `path_provider` и использует полный путь.

**5. Как обеспечить читаемость данных в текстовом файле?**

Использовать UTF-8, понятные подписи полей, каждое значение на отдельной строке и разделитель между анкетами. Не допускать управляющих символов в пользовательском вводе. В этом проекте формат совпадает с образцом задания.

**6. Какие меры защищают записанные данные от несанкционированного доступа?**

Хранить файл в каталоге приложения с ограничениями ОС, не запрашивать общий доступ ко всем файлам устройства, не отправлять анкету в сеть и не включать её в Git или архив исходников. В проекте `anketa.txt` добавлен в `.gitignore`, нативная версия использует каталог приложения, данные не отправляются на сервер. Файл по условиям задания остаётся обычным текстовым и не зашифрован. Для реального приложения с чувствительными данными понадобятся шифрование и безопасное хранение ключа в Keychain/Keystore, а также управление экспортом и удалением. Скачанный web-файл защищается правами выбранной пользователем папки и настройками устройства.

## Проверка

```sh
flutter analyze
flutter test
flutter test test/anketa_test.dart
flutter build web --release
```

Тесты анкеты проверяют невалидные поля, точный формат записи, кириллицу, добавление двух записей в настоящий временный файл, ошибку записи, запрет сохранения неверной формы, блокировку повторного запроса, очистку предварительно заполненных полей и сохранение ввода при ошибке.
